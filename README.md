# Numa for Runtipi

A [Runtipi](https://runtipi.io) app store with [Numa Home](https://github.com/simmmmm/numa-home): your household's photographs on your own server.

To add it, open Settings › App Stores in Runtipi and add the URL of this repository.

Numa Home is published for x86-64 (amd64) only.
